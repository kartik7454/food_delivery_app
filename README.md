## Project Summary
Developed a full-featured food delivery application enabling users to browse menus, place
orders, and make secure online payments and a dashboard for owner.
• Built a scalable RESTful API using Express and MongoDB to manage orders, menus,
users, and integrated it with third-party services for payments .
• Designed an intuitive frontend using Next.js, React, and Tailwind CSS, ensuring mo-
bile responsiveness and performance.
• Deployed the application on Vercel with a backend powered by Node.js and TypeScript
for type-safe development

## Tech Stack
 MERN Stack, Next.js, Vercel, TypeScript, Tailwind CSS
